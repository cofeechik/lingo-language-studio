# LINGO — студия языков

**Живая версия:** https://cofeechik.github.io/lingo-language-studio/

Лендинг вымышленной языковой студии. Портфолио-проект.

Арт-дирекция — **«Живой алфавит»**: сайт держится на кинетической типографике
и языковых символах, а не на фотографиях и карточках. Приветствие в hero
переключается между языками буква за буквой; шкала A1 → C2 нарисована
переменными осями шрифта, а не виджетом.

> LINGO — вымышленный бренд. На странице нет реальных данных: ни статистики,
> ни рейтингов, ни наград, ни настоящей команды. Цены в секции тарифов —
> часть макета, о чём прямо сказано на самой странице.

## Стек

- Vite + React 19 + TypeScript
- Чистый CSS с токенами, без UI-библиотек и без анимационных зависимостей
- Шрифты: **Archivo** (variable: `wdth` 62–125, `wght` 100–900) — дисплейный,
  **Instrument Sans** — интерфейсный
- Фотографии: Unsplash CDN, без общего фильтра

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173/` — dev-сервер сам перебросит на
`/lingo-language-studio/`. Этот путь задан в `vite.config.ts` как `base`,
потому что сайт публикуется как GitHub project page; dev, `npm run preview`
и продакшен-сборка используют один и тот же префикс.

## Публикация

`.github/workflows/deploy.yml` собирает проект и деплоит `dist` через
официальные Pages-экшены при каждом push в `main`. В настройках репозитория
источник Pages — **GitHub Actions** (не ветка).

```bash
npm run build     # tsc -b && vite build
npm run preview   # проверить собранный dist локально
```

## Маршруты

| Путь | Что это |
| --- | --- |
| `/lingo-language-studio/` | лендинг |
| `/lingo-language-studio/trial/` | анкета записи на пробный урок |

Роутер свой, без библиотек: `history.pushState` плюс делегированный обработчик
кликов. Все CTA остаются обычными `<a href>` — работают в новой вкладке и без JS.
Якоря вида `#languages` не перехватываются и продолжают скроллить страницу.

Сборка кладёт рядом с `index.html` ещё `trial/index.html` — GitHub Pages
отдаёт его со статусом 200 (одного `404.html` мало: он вернул бы страницу,
но с кодом 404). `404.html` остаётся как подстраховка.

### Контекст в анкету

CTA передают выбор пользователя параметрами:

- `?language=english|deutsch|espanol|francais|italiano|portugues` — со строки языка
- `?course=speak|work|zero|exam|travel|teens` — с ячейки направления
- `?tariff=solo|duo|group` — с кнопки тарифа

Язык и цель открываются уже отмеченными, тариф попадает в итоговую заявку.
Отправки на сервер нет: анкета собирает текст и передаёт его в share-ссылку
Telegram, где человек сам выбирает чат. Ни бэкенда, ни Bot API, ни токенов.

## Цвет

Один базовый, один акцент, нейтрали:

| Токен | Значение | Роль |
| --- | --- | --- |
| `--ink` | `#14170F` | база, тёмная поверхность |
| `--accent` | `#FF5B2E` | единственный яркий акцент |
| `--paper` | `#F2EFE6` | светлая поверхность |

Поверхности переключаются атрибутом `data-surface="paper" | "accent"` —
он переопределяет `--fg`, `--hair`, `--bg`, поэтому компоненты не знают,
на каком фоне они стоят.

## Композиции секций

Каждая секция решена по-своему, а не одним шаблоном карточки:

- **Hero** — типографическая сцена, приветствие морфится между языками
- **Языки** — индекс-список: hover открывает ось ширины и поднимает фото под курсором
- **Обучение** — «лестница» из трёх шагов на общей оси, которая заполняется при скролле
- **Направления** — модульная full-bleed сетка, hover инвертирует ячейку в акцент
- **Преподаватели** — контактный лист: разные кропы, разные вертикальные сдвиги
- **Тарифы** — колонки, разделённые волосяными линиями, без боксов и бейджей
- **Финал** — сплошной акцентный экран, кинетическое слово замыкает круг

## Анимация

Движение подчинено идее языка: смена слов по буквам, оси `wdth`/`wght` на
hover, заполнение шкалы уровней. Появление секций — только для крупных
заголовков. Всё отключается при `prefers-reduced-motion`.

## Адаптив

Брейкпоинты: `370 / 560 / 720 / 860 / 900 / 960 / 1024`.
Проверено без горизонтального скролла на 360–1600 px.
